썸네일이 없는 **샘플 글**입니다. 이미지 없이도 제목과 설명이 자연스럽게 배치됩니다.

## 글의 구조

| 요소 | 목적                          |
| ---- | ----------------------------- |
| 제목 | 문서의 구조를 보여 줍니다     |
| 설명 | 글의 내용을 간단히 소개합니다 |
| 링크 | 관련된 기록으로 연결합니다    |

> 잘 정리한 글은 미래의 나에게 보내는 친절한 메모입니다.

### 확인 목록

- [x] 간결한 제목
- [x] 의미 있는 소제목
- [ ] 나만의 첫 글 작성

~~너무 많은 장식~~ 대신 읽기 편한 문장을 남깁니다.
